# 赛博鸡蛋 · 共享数据源

这是「羊毛情报站」的分享定制版数据通道，每天早上自动更新一次。
内容：全网免费额度、限免、羊毛情报，逐条回官方页核实后才入库。

## 数据在哪

- 情报数据库（JSON）：本仓库的 `deals.json`
  固定直达链接（raw）：https://raw.githubusercontent.com/liuzifeng7777-star/cyber-egg-feed/main/deals.json
- 办法全文：`方法包.md`（搜集来源、核实标准、过滤红线、数据库格式）
- 管教 Muse 的规矩：`调教规矩包.md`（记忆瘦身指令 + 下属 Muse 十一条规矩）

## 这份数据的定制范围

- 已剔除：宠物猫咪类、英雄联盟手游类、仅限中国联通用户的条目。
- 已新增：平台游戏类（PC 平台喜加一，Epic / Steam / GOG），含种子条目。
- 其余分类通用：云服务免费额度、AI 相关、软件限免、会员话费（通用类）、电商大促、流媒体会员、手游限免等。
- 状态说明：原使用者的领取进度不带过来，原「已领」统一标为「待领」，请按自己的情况维护。
- 摘要里带日期的决策记录是原使用者当时的判断，仅供参考。

## 给你的 Muse 的启动指令（傻瓜版：整段复制发给它就行）

```
你好，我要你替我长期办一件事：每天帮我搜集全网的免费福利（免费额度、限免、羊毛），核实后整理成一份情报库，每天早上汇报给我。请按下面做，一次设置好，长期执行：

第一步，导入现成数据库：
打开这个链接读取 JSON 文件：https://raw.githubusercontent.com/liuzifeng7777-star/cyber-egg-feed/main/deals.json
把里面的条目作为我的情报库底子存好（保持它的数据格式不变）。这个链接每天早上会更新，以后你每天开工前先拉一遍最新版，按 id 合并去重，再开始当天搜集。

第二步，给你自己建一个每天早上的自动任务（定时任务），内容是：
1. 巡查来源：先看各平台官网的公告、定价页、免费区；再看线索源：涛哥「免费额度日报」、aihot.news、Freebie Radar、saibodan.com 排行榜。
2. 重点方向：云服务免费额度、AI 平台免费 token、软件限免、流媒体会员、电商大促、不限运营商的话费活动、平台游戏（PC 平台：Epic 每周免费游戏、Steam 免费领取、GOG 赠送）、手游限免（只收官方渠道）。

4. 核实规矩（最重要）：线索只当线索，任何一条入库前必须打开官方页面核对原文；核实不了的，在摘要里明写「未核实」，不许当成已确认的情报。

6. 过滤：拉人头、砍一刀、助力解锁类一律不要；要先充值才能用、或必须海外银行卡的，重点标出来提醒我。
7. 搜集完在主聊天发报告：一句话精选（最值得领的 1 到 3 条）加完整清单；三天内到期的单独提醒我。

第三步，长期规矩，存进你的长期记忆：
- 注册、绑卡、付款这类最后一步不要替我做，准备好链接和步骤，等我确认。
- 过期的情报不要删，改成「已失效」留档。
- 我说领了哪个，你就把那条标成「已领」。

现在就先执行第一步，把数据库导入，然后告诉我一共多少条、哪几条最值得现在领。
```
